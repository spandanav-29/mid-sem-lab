CineScope - IMDb Movie Explorer

Deployment instructions:
1. Keep app.py, requirements.txt, and your dataset CSV in this folder.
2. The dataset filename expected by app.py is:
   ToP 250 movies on imdb in 2026.csv
3. Upload all three files to a GitHub repository.
4. Deploy app.py using Streamlit Community Cloud.

IMPORTANT: The CSV dataset was not included because it was not attached here. Add your original CSV file with the exact filename above before deployment.
